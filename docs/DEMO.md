# Сценарий защиты и честный список моков

## Что говорим про данные (честно, в начале демо)

| Что | Реально или мок |
|---|---|
| Направления (8 штук) и климат | реальные направления; климатические нормы приблизительные |
| Погода | **реальная**: Open-Meteo Archive, фактическая погода тех же дат прошлого года (без сети — климатическая норма, в UI подписано) |
| Отели (40) | **вымышленные** названия в реальных районах; звёзды, номера, признаки, отзывы — синтетика |
| Цены и наличие | **мок** вместо API Островка: база × сезон × день недели × номер × гости |
| Авиабилеты | **мок** (расстояние, сезон, время суток). С `TRAVELPAYOUTS_TOKEN` калибруется по реальному кэшу цен Aviasales |
| Поезда | расписание — таблица, составленная вручную по открытым данным; цены — **мок** |
| Трансферы | **мок**: расстояние по координатам × тариф |
| Ролики | **процедурные иллюстрации** со слайдшоу-наездом, в кадре метка «Демо-ролик · иллюстрация, не фото отеля». Поддержан `video_url` для настоящих роликов |
| Озвучка | синтез речи браузера (Web Speech API), текст генерирует бэкенд |
| Оплата и бронь | **имитация**, на экране оплаты это написано |
| LLM | по умолчанию **не используется**: разбор правилами. С `ANTHROPIC_API_KEY` LLM дополняет разбор |

## Сценарий (7–8 минут)

1. **Размытый запрос из кейса** — «Хочу к тёплому морю в ноябре, недорого, с ребёнком, без долгих перелётов».
   Показать чипы «Агент понял»: пунктиром то, что додумано (возраст ребёнка, город вылета) — их не спрашиваем сейчас, проверим перед оплатой. Карточки направлений: почему, сколько стоит, погода, сколько лететь. Дубай отсеян: лететь дольше 5 ч.
2. **Лента** — ролик, озвучка, субтитры, плашка цены и «≈ с дорогой». 3 лайка → подборка открывается сама.
3. **Подборка** — приоритеты «по свайпам», у каждого варианта «почему / чем жертвуем / риски», бейджи сравнения.
   Правка: «а если на два дня позже?» → цены пересчитаны, лайки и подборка на месте.
4. **Оформить** — шаги сборки идут потоком (SSE): цена → билеты → трансфер → состыковки. Объяснение пакета.
   Переключить «Удобный / Дешёвый / Быстрый» — выбор из уже найденного, без нового поиска.
   Правка «с нами едет собака» → отель без животных заменён, баннер «Пересчитано: … Сохранено: …».
   «Что-нибудь ещё?» → «нужен ранний заезд» → «передам отелю».
5. **Оплата (демо)** → план по часам и ваучеры.
6. **Сценарий 2** — «Азур Бэй Сочи, номер делюкс с видом на море, 3–10 декабря, двое взрослых»: лента пропущена, сразу пакет.
7. **Каверзные** — «Тёплое море в январе, но только на поезде из Москвы» → один уточняющий вопрос с вариантами. «Неделя в Дубае на двоих за 30 тысяч» → «в бюджет ничего не помещается» + варианты ослабить.
8. **🧠 «Как думал агент»** — узлы графа и время. `GET /metrics` — метрики на 20 тестах.

## Запасной план

- Без сети всё работает (`OFFLINE=1`): погода из климатических норм, остальное — моки.
- Перед защитой: `OFFLINE=1 .venv/bin/python -m tests.run_metrics` — должно быть «20 из 20».
- Запасное видео прохода записать заранее (скринкаст экрана телефона).

## Репетиция на незнакомых запросах (проверено)

«хочу в горы покататься на лыжах в феврале втроем», «летим с женой на годовщину куда-нибудь где тепло, бюджет 400 тысяч, вылет из Екатеринбурга», «съездить в Казань с мамой и сыном 12 лет на неделю в январе на поезде», «на машине в Сочи с собакой на майские», «Хочу в Париж на выходные» (→ честно: нет в каталоге, предложить похожее) — все доходят до оплаты.
